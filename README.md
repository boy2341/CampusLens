## 🎯 Problem Statement

CampusLens aims to solve this by building an AI-powered campus intelligence layer that can understand natural-language requests, analyze images, classify campus issues, intelligently match lost and found items, and provide contextual event and academic recommendations

| **Add-ons** | Docker setup, TailwindCSS, Socket.io |

---

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

```bash
cp server/.env.example server/.env
```

### 3. Run Development Servers

- **Frontend:** `npm run dev:client`
- **Backend:** `npm run dev:server`
